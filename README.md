# Chrono Chicken

* Set number of players
    - Blue
    - Red
    - Green
    - Yellow
* Set the timeout (in seconds)
    - Fixed
    - Variable with min and max
* Set difficulty
    - Very easy: show 3 decimals (12.345 seconds)
    - Easy: show 2 decimals (12.34 seconds)
    - Normal: show 1 decimal (12.3 seconds)
    - Hard: show no decimals (12 seconds)
    - Very hard: show no number (empty)
* Set speed
    - Normal
    - Variable with min and max
* Set the game mode
    - Infinite
    - First to reach X
    - Best of X
    - Battle royale
        - In each round, the player with the worst score is eliminated
* Scoring
    - 1 point per win
    - Make score proportional to how close they got to zero
    - Adding the remaining time, the first one to reach X loses
* Madness mode
    - The counter starts as soon as the previous round ends (no need for all players to press their buttons to start)
* Environmental modifiers
    - Shake countdown
    - Rotate countdown vertically
    - Rotate each digit horizontally
    - Screen goes dark for some time
    - Countdown blinks
    - False audio tick feedback
    - Shrinking Zones: As the timer gets closer to zero, the buttons get physically smaller. If a finger slips out of the zone, it counts as a release.
    - Moving Zones: the buttons move around the screen and each player has to follow their path. If a finger slips out of the zone, it counts as a release.
* Show an animation of who wins each round
* Audio
    - Play a sound when the round starts (i.e. all players press their buttons)
    - Play a sound when somebody reaches zero
* Online mode
